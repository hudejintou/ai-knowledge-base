## 关键发现

1. **top_k 影响错误方向**：top_k=3 时问题是"误作答"（上下文宽），top_k=1 时问题是"误拒"（佐证少）——top_k=3 + 严格 Prompt 是当前最优组合；top_k=2 待补。
2. **Prompt 漂移实证**：实验 13 只改了 `rag_v1.py`，`backend/qa/config.py` 仍是旧宽松版 → 接口与评估用的不是同一份 Prompt。解耦只做了一半（config.py 建了，但 rag_v1.py 没接入），这是"复制导致漂移"的活案例。
3. 严格 Prompt 的代价目前为 0 误拒，但 HOLDOUT 已非盲测、样本仅 46 题，结论仍需保持警惕。

## 方法论收获

- 对照实验要一次只动一个变量：实验 13 只改 Prompt、实验 14 只改 top_k，结论才可归因。
- 参数的影响是双向的：放宽检索上下文和收紧判断标准会朝相反方向制造错误。
