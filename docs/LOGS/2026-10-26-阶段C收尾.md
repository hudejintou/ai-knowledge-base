# 2026-10-26：阶段 C 收尾（top_k 梯度 + 切分实验 + 结论定稿）

## 今天做了什么

### 实验 15：top_k=2 对照
- 严格 Prompt、语料、评估集不变，仅 top_k 3→2，RUNS=1。
- 结果：100%（46/46），无误拒无误答。top_k=2 与 3 表现一致。

### 实验 16：top_k 1/2/3 稳定性验证（RUNS=3）
- 每个 top_k 每题 3 次，分母 138。
- 结果：top_k=1 为 99.28%（「Redis 拿来当缓存用时要注意什么？」3 次中 2 次误拒）；top_k=2、3 均 100%。
- 结论：实验 14 的 top_k=1 误拒是概率性偶发；严格 Prompt 下 top_k 降到 1 会增加误拒概率。

### 实验 17~19：切分块大小实验（200/400/800，重叠 50，top_k=3）
- 实验 17：预实验（corpus_ai.txt，7 段 14 题，v2 判定规则）。
- 实验 18：正式实验（corpus_v3_all.txt，4 篇权威来源改写、24 段，44 题单段）。
- 实验 19：加入 4 道跨段题（48 题）。
- 结果：单段题 400 的 top-1 最高（75%），top-3 与 800 持平；小块 200 在跨段题上明显不足（top-3 50%）；跨段题仅 4 道只能看方向。

### 阶段 C 收尾结论（已写入 EXPERIMENTS.md 汇总区）
- **top_k**：严格 Prompt 下 2 与 3 无误拒（RUNS=3），1 有偶发误拒。
- **切分**：单段题 400 的 top-1 最高，top-3 与 800 持平；跨段只看方向。
- **默认候选**：块大小 400、重叠 50、top_k=3——候选值，未固定到代码，待更大规模验证。
- 适用范围：本语料 24 段、48 题、单次运行、自定判定规则。

## 方法论收获

- RUNS=3 是区分"偶发"与"稳定"的唯一手段：实验 14 的单次误拒差点被当成 top_k=1 的稳定缺陷。
- 对照实验要控制变量到只剩一个：top_k 系列只动 top_k，切分系列只动块大小。
- 判定规则（重叠 ≥50%、跨段题需每段命中）是自定的，它决定了"跨段 top-1 几乎不可达"这类现象，结论必须连同规则一起声明。
