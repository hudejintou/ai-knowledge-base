## 设计要点（与 ROADMAP 的小项目目标对齐）

- **不依赖 RAG**：通用 Agent 能力与主项目互补，不重复。
- **手写循环不上框架**：工具注册与描述、多步规划、错误恢复与超时、可观测性（步数上限 + 完整 trace）都自己实现——学习重点正是这些机制本身。
- 结构清晰：`agent/` 下 config / model / registry / loop / tools 分层，附测试。

## 方法论收获

- 白天实验 33 学到的"错误隔离"思想直接复用到 Agent 设计：单工具失败不炸整个循环，结构化错误回传给模型让它决定下一步。
- 超时要分两层：单工具超时和整体循环超时（60s）是不同的东西，都要设。
