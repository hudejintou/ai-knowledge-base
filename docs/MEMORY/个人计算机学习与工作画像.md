## 14. 使用 AI 辅助开发的原则

AI 应该作为：

- 编程助手
- 代码解释器
- Debug 助手
- Code Review 助手
- 技术方案讨论对象
- 学习助手

而不是完全替代自己的开发能力。

推荐工作流：

```text
理解需求
   ↓
自己分析
   ↓
AI 辅助设计
   ↓
确认方案
   ↓
AI 辅助编码
   ↓
自己阅读代码
   ↓
运行测试
   ↓
Debug
   ↓
Code Review
   ↓
总结
```
