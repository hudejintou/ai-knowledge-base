# LONG_TERM_GOALS（长期目标）

> 用途：职业目标、里程碑、项目范围。执行排期与验收标准见 AI_ROADMAP「接下来学习大纲」。

## 职业目标（唯一记录处）

- **核心定位**："既懂后端工程，又懂 AI，并且能把 AI 真正做成可以运行、可以部署、可以解决实际问题的软件。"
- **方向**：AI 应用工程 / AI 工程（后端 + AI + LLM 落地），非纯算法研究。
- **节奏**：2027-01 整理作品简历并对标 JD → 2027-02 投递面试 → 2027-03 前后依据实际机会评估转岗，不把拿到 offer 设为确定性里程碑。

## 里程碑

| 时间 | 节点 |
|------|------|
| 2026-10 | LLM API 实践收尾 + RAG 起步验证（已达成） |
| 2026-11~12 | RAG 主项目 v1 + 工程化（DRF、Redis/Celery、Docker） |
| 2027-01 | 项目打磨 + 求职准备（作品、简历、JD 对标） |
| 2027-02 | 投递简历、面试 |
| 2027-03 | 评估转岗机会，按实际情况决策 |

## 项目范围（至 2027-02，只做 1+1）

- **主项目**：企业知识库 RAG 后端（Django/DRF + 本地 Embedding + 检索引用问答 + 工程化）。
- **小项目**：轻量 Function Calling / Agent（手写调用循环，不引重框架）。
- 其他想法（AI Coding Assistant、本地助手、小程序+AI 等）仅作储备，不并行立项。

## 副业

"有机会再说"，不占核心排期；先有可验证作品，再谈变现。
