# LONG_TERM_GOALS（长期目标）

> 用途：保存长期职业目标、AI 转行目标、项目目标、副业目标。
> 更新：2026-09-20 初版；2026-10-14 收敛为 1 个 RAG 主项目 + 1 个轻量 Agent 小项目，并按实际转岗节奏调整。

## 长期职业 / 转行目标

- **中期**：在后端开发基础上，用半年时间、以 AI 加速的方式学习 AI，**半年后转战 AI 行业、换工作**（目标：AI 应用工程师 / AI 工程相关岗位）。
- **方向**：AI 应用工程 / AI 工程（后端 + AI + LLM 落地），非纯算法研究。
- **核心竞争目标**：
  > "既懂后端工程，又懂 AI，并且能把 AI 真正做成可以运行、可以部署、可以解决实际问题的软件。"

### 项目目标（至 2027-02）

经过范围收敛，当前只维护 **1 个主项目 + 1 个小项目**，确保做深、能解释、可展示：
- **主项目：企业知识库 RAG 后端**：优先 Django/DRF；包括文档切分、本地 Embedding、检索、带引用的流式问答，逐步增加 Redis/Celery、Docker Compose 和 20-30 条评估集。
- **小项目：轻量 Function Calling / Agent**：沿用手写多步调用循环，完善安全性与测试；暂不先上重型 Agent 框架。
- 其他 AI Coding Assistant、本地助手、自动化工具等保留为未来备选，不并行立项，不计入当前主计划。

### 副业目标

副业接单/外包降级为“有机会再说”，不进入当前核心学习排期。优先完成主项目、沉淀可验证作品与真实问题解决能力，再依据机会决定是否尝试。

```

  ↓ 尽早 AI 实战
  ↓ 做深 1 个 RAG 主项目 + 1 个轻量 Agent 小项目
  ↓ 积累 GitHub/简历作品
  ↓ 2027-01 求职准备，2027-02 开始投递和面试
  ↓ 依据实际机会评估转向 AI 应用工程岗
```

### 核心策略

- **AI 加速，不从头学**：尽可能借助 AI（本地模型 + API）完成学习和开发。
- **从实际项目入手**：先做出东西再讲原理。
- **范围收敛**：只做 1 个 RAG 主项目 + 1 个轻量 Agent 小项目；副业接单不占主计划。
- **快速迭代**：快速进入实战，快速试错，快速迭代。
- **设备适配**：明确区分 Mac / Apple Silicon 与 NVIDIA CUDA 的差异，不把 Linux/NVIDIA 教程照搬。
- **内存约束**：16GB 内存下，跑不动的方案直接说明原因（模型大小、量化、内存压力）。
- **主业持续成长**：不放弃后端开发主业的持续学习。
