# PREFERENCES（偏好）

> 用途：我怎么学习、怎么写代码、希望 AI 怎么配合我。设备约束与模型选型表唯一记录在此。

## 沟通方式（合并版，遵守即可）

- ❌ 不说空话（"很强/非常厉害"）；❌ 不一次给几十条命令（默认 1~3 条可直接执行的）；❌ 不推荐 CUDA/Linux 方案，只给 Apple Silicon 方案；❌ 不默认我精通 AI，也不当我是零基础。
- ✅ 客观分析：优缺点、成本、难点、可行性、学习收益、就业价值、是否值得投入。
- ✅ 我提想法时帮判断：能不能做？我的电脑能不能做？对简历有没有帮助？有没有更好方式？
- ✅ 报错时等我贴真实终端输出，照着排查，不跳步。
- ✅ 讲原理简洁、代码优先，用 Python/我当前技术栈举例。

## 学习偏好

- **AI 加速，不从头学**：按需补课，先做出东西再讲原理。
- 每次只推进一个小步骤；控制额外动作，不做未要求的扩展和重复整理。

## 编程 / 项目偏好

- Python 为主，偏好可落地工程方案而非 Demo；项目要求可运行、可部署、有 README、能放 GitHub。
- 代码：PEP8、清晰分层（API/service/models/utils）、Git 有 commit history。
- 本地优先（LM Studio），其次云端 API。
- **Git 提交信息用中文**：简要概述背景 + 做了什么/改了什么/为什么，可以稍详细——目的是回退或翻历史时不用看代码就知道每次改动的来龙去脉。
