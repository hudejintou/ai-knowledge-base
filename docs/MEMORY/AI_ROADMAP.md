- **核心约束**：仅 16GB 内存，需特别重视模型大小、量化、推理速度、磁盘与内存压力。

### 模型选择建议（基于 16GB 内存）

| 模型 | 原始大小 | 建议量化 | 内存占用（近似） | 备注 |
|------|---------|---------|-----------------|------|
| Qwen3.5 7B | ~4.7GB | 4-bit Q4_K_M | ~3-4GB | 日常辅助首选 |
| Qwen3.5 9B | ~7GB | 4-bit Q4_K_M | ~4.5-5GB | 平衡性能与效果 |
| Qwen3-27B | ~21GB | - | **跑不动** | ⚠️ 明确不建议 |
| Llama-3.1-8B | ~4.7GB | 4-bit | ~3-4GB | 备选 |
| GLM-Edge-9B | ~5GB | 4-bit | ~4-5GB | 备选 |
| Phi-3.5-mini | ~2.3GB | - | ~1.5-2GB | 轻量级首选 |

**推荐配置**：Qwen3.5 9B Q4_K_M（约 5GB）+ Phi-3.5-mini Q4_K_M（约 2GB），双模型轮替，平衡性能与资源占用。
