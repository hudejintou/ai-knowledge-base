## 如何新增一个项目

1. 在 `PROJECTS/` 下新建目录，如 `PROJECTS/rag-knowledge-base/`。
2. 在该目录创建 `README.md`，写明：目标、技术栈、进度、关键决策、下一步。
3. 重要实验与过程记录同时写入 `docs/EXPERIMENTS.md` 或 `docs/LOGS/`。
